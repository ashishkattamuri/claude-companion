# Contributing

Thanks for your interest in contributing to Claude Companion.

This project is early. The goal is to explore what it would take to make Claude Code feel more like a personal engineering assistant.

## Project Direction

Claude Companion is a wrapper around Claude Code, inspired by Muse.

The focus is not to replace Claude Code, but to build the missing companion layer around it: something more continuous, more aware of ongoing work, and more useful across real engineering workflows.

## Useful Contributions

At this stage, useful contributions include:

- Ideas and design notes
- README and documentation improvements
- Workflow examples
- Small prototypes
- CLI experiments
- Context and memory design
- Task and follow-up flows

## Principles

Please keep contributions aligned with the spirit of the project:

- Keep it simple
- Keep the user in control
- Make behavior easy to understand
- Prefer practical workflows over complex abstractions
- Avoid unnecessary infrastructure
- Do not store secrets by default

## How to Contribute

1. Open an issue for ideas, bugs, or proposed changes.
2. Keep pull requests small and focused.
3. Explain why the change is useful.
4. Include examples where possible.
