# Feature clips

Short silent clips of each feature, cut from the [demo video](https://www.youtube.com/watch?v=Em9um7jZJz0). Real recordings of Companion for Claude running real Claude Code sessions.

| File | Feature |
|---|---|
| `01-session-groups.gif` | Sessions grouped by what they need: Needs you, Running, Earlier |
| `02-search.gif` | Full-text search across every conversation |
| `03-every-step.gif` | Every step of a session, with exact diffs and command output |
| `04-morning-recap.gif` | The morning recap and "Continue its session" |
| `05-context-window.gif` | Context window meter and breakdown, Compact, Pinned files |
| `06-audit.gif` | Audit: where a session's tokens went, and what to fix |
| `07-sub-sessions.gif` | Branching into linked sub-sessions; the parent as a decision log |
| `08-earlier-lookup.gif` | A sub-session looks up a detail in the original conversation, word for word |
| `09-side-chats.gif` | Side chats: ask about a message without adding to the chat |
| `10-notes-and-handoff.gif` | Session notes and hand-off to a fresh session |
| `11-terminal-sync.gif` | One live session in Companion, its terminal pane and any attached terminal |
| `12-guardrails.gif` | New sessions: model, plan first, ask before edits, own git worktree |
| `13-review.gif` | Review a session's changes like a pull request |
| `14-approvals.gif` | Permission prompts answered in the conversation |
| `15-connectors.gif` | Plugins, marketplaces and MCP servers in one place |
| `16-cache-timer.gif` | Cache timer: how long the prompt cache stays warm, and what a cold resume costs |
| `17-cache-misses.gif` | Cache misses explained: how much a turn processed again, and why (model switch, expiry, compaction, tool changes) |
| `18-compaction-history.gif` | Compaction history: before and after sizes, who started it, and the summary Claude works from |
| `19-heaviest-in-context.gif` | Heaviest in context: the biggest tool results Claude still carries, with a jump to each and "Compact without these" |
| `20-cache-warnings.gif` | Warnings before a model switch or an MCP server change makes running chats reprocess their context |
