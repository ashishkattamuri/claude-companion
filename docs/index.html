The problem

Every long session ends the same way.

Wait, we already decided that.

After a compaction, the reasons behind your decisions are gone, and the agent starts arguing them again.

Why did that turn cost so much?

Every message re-reads the whole history. A model switch or a long pause makes the agent reprocess all of it.

Let me explain the project again.

A new chat starts from zero. So you either drag the old one along, or you repeat yourself.

It's not just you: models get measurably less reliable as their input grows. Chroma, “Context Rot”

How Companion fixes it

Treat context as something you manage.

01

See it before it hurts.

Know what fills a session, what the next turn will cost and where tokens are going to waste, before the quality slips. Companion warns you before an action makes your running chats reprocess everything.

Context breakdown · Cache warnings · Audits
02

Split the work, keep the memory.

When the conversation forks, branch it. The new chat starts with the plan as background, keeps its own thread clean, and can look up anything from the original word for word. Side questions get answered on the side, without growing the chat.

Linked sub-sessions · Side chats
03

Pick up exactly where you left off.

Every session keeps living notes: the goal, each decision and why, the commands that worked. Hand off to a fresh session without re-explaining, and start the morning from a recap instead of a transcript.

Session notes · Hand-off · Morning recap

Install

Up and running in a minute.

Download and drag to Applications

You need Claude Code installed and signed in. Companion runs on your own login, so there's no API key.

Apple silicon (.dmg) Intel (.dmg)

Open it the first time

The app isn't notarized by Apple yet, so macOS asks once. Open it, then go to System Settings → Privacy & Security and click Open Anyway. Or run:

xattr -dr com.apple.quarantine \
  "/Applications/Companion for Claude.app"

Optional: the companion command

The CLI ships inside the app. Link it onto your PATH:

sudo ln -sf "/Applications/Companion for Claude.app/Contents/Resources/bin/companion" /usr/local/bin/companion
# let every session branch
companion tools install
Everything stays on your Mac. No account, no server, no telemetry. Notes and summaries run through claude -p on your own login. MIT licensed. Prefer to build it yourself? See the README.
