Keep every Claude Code session focused.

Companion for Claude is a desktop app around Claude Code. It keeps every session in one window, shows what each one carries in its context, and gives you the tools to keep it lean: notes, hand-offs, linked sub-sessions and side chats.

Companion for Claude

Real recording. “Open a separate chat for the caching workstream” opens a linked session that already knows the plan.

Why

Long sessions get slower, pricier and less accurate as their context fills up.

One chat rarely stays one topic. Forty messages later the plan you made is buried under detours, every turn pays for all of it again, and when the session ends its decisions sit in a transcript nobody reads. Companion treats context as something you manage: see it, keep it focused, split it when the work splits, and carry what matters into the next session.

01 SEE

Know what each session is carrying.

Context window

See what fills the context

A meter sized to the model's real limit, broken down from Claude Code's own /context: system prompt, tools, MCP tools, skills, messages and the autocompact buffer.

Compact with a focus, and pin the files the work depends on so they survive compacting.

Prompt cache

Know when a turn reprocesses everything

See how long the cache stays warm, what a cold resume costs, and why a turn missed it: a model switch, expiry, compaction or a tools change. Companion warns before an action would break the cache for running chats.

Audit

Find where the tokens went

Files read again and again, approaches retried after they failed, full test suites run when one test would do. Each finding comes with its cost, its likely cause in your setup and a fix, confirmed by a second model.

02 STEER

Split the context when the work splits.

Sub-sessions

Branch into linked chats

  • Say “open a separate chat for…” and a new session starts on it right away.
  • It knows the parent's notes and recent exchanges as background, so its own thread stays clean.
  • It can look up any detail from the earlier chat, word for word.
  • The parent becomes a decision log of every chat opened from it.
Side chats

Ask on the side

Ask about any message in a thread beside the chat. Claude answers with the whole conversation in mind, but nothing you ask is added to it, so the chat doesn't grow. Answers come from a fork that reads from the prompt cache, and show their cost.

Notes & hand-off

Carry decisions forward, not transcripts

After each turn Companion keeps a Markdown notes file: the goal, decisions with their reasons, paths, commands, errors and fixes. When a session runs long, Hand off opens a fresh one from the notes and pinned files.

03 TRUST

Every session in one window, every change reviewed.

Sessions

Grouped by what they need from you

Live and recent sessions from all your projects: Needs you, Running and Earlier. A session stuck on a question moves to the top, and permission prompts can be answered right in the conversation.

Review

Review a session like a pull request

One net diff per file, a short explanation of why it changed, and Claude's own words beside each edit with a link to that moment in the chat. Built from the session's record, not git, so it shows exactly what the AI changed.

Terminal sync

Drive a session from anywhere

Sessions run as Claude Code background sessions. Type in Companion, its terminal pane, or any terminal attached with claude attach: it's one live session, and every place shows the same thing.

Install

Up and running in a minute.

Download and drag to Applications

You need Claude Code installed and signed in. Companion runs on your own login, so there's no API key.

Apple silicon (.dmg) Intel (.dmg)

Open it the first time

The app isn't notarized by Apple yet, so macOS asks once. Open it, then go to System Settings → Privacy & Security and click Open Anyway. Or run:

xattr -dr com.apple.quarantine \
  "/Applications/Companion for Claude.app"

Optional: the companion command

The CLI ships inside the app. Link it onto your PATH:

sudo ln -sf "/Applications/Companion for Claude.app/Contents/Resources/bin/companion" /usr/local/bin/companion
# let every Claude session branch
companion tools install
Prefer to build it yourself? Clone the repo, then npm install && npm run build && npm link, or npm run dist:mac to make the .dmg. See the README.
Privacy

Everything stays on your machine.

Companion reads Claude Code's transcripts into a local SQLite database. Summaries, notes, reviews and audits run through claude -p on your own login, isolated and capped per run.

  • No account, no server, no telemetry
  • Model calls run with no tools, hooks or MCP servers, and aren't saved as sessions
  • Opt whole projects out with a glob in a config file
  • companion doctor shows how many model calls were made
  • MIT licensed: read every line

Give your sessions room to think.
